# Furphy Addon Manager - ad/tracker host list for the optional CurseForge
# ad filter (Settings > Browsing > "Filter ads and trackers in the
# CurseForge tab"). OFF by default.

# One host per line. '#' starts a comment (whole-line or trailing after
# whitespace is NOT stripped - keep comments on their own line). A listed
# host blocks itself and any subdomain of it (e.g. "doubleclick.net" also
# blocks "ad.doubleclick.net"). This file is user-editable; FurphyHost.exe
# reads it fresh each time the CurseForge tab's ad filter is (re)armed.
#
# NEVER add curseforge.com, forgecdn.net, overwolf.com, cloudflare.com or
# cloudflareinsights.com here - those are hard-allow-listed in code and
# would be ignored anyway, but keep this file honest.
