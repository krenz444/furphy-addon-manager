Furphy Addon Manager

Automatic World of Warcraft addon updates. No account, no API key, nothing to configure.

Download Furphy Addon Manager

Free. For Windows 10 and 11. Works with World of Warcraft retail, Classic, and Classic Era.

Getting started

  1. Download the zip above, then right-click it and choose Extract All.
  2. Open the folder you just extracted.
  3. Double-click Install Furphy.cmd.
  4. If Windows shows a small "Open File - Security Warning" box, click Run. (See the note below - it's expected, and harmless.)
  5. Click Install in the window that opens - Furphy finds your WoW folder automatically. When it's done, click Open Furphy Addon Manager.

Windows may show a small "Open File - Security Warning" box the first time you run Install Furphy.cmd, since it isn't signed with a paid certificate yet - click Run. Furphy only writes inside your WoW folder and never asks for admin access.

Uninstalling: right-click the tray icon, or open Settings inside Furphy, or use Windows Settings > Apps - your addons always stay in WoW either way.
